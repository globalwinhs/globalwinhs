## 我的介绍

我叫何胜，2010 年进入外贸一线。现在，我把长期业务实践中积累的判断、方法和工具，整理成外贸人能直接使用的内容、行动指南和 Agent Skills，帮你少走弯路、减少重复劳动，把每一次获客沉淀成下一次增长的基础。

## 我在做的事

- **询盘复利行动指南**：围绕真实外贸问题，给出判断方向和下一步行动。
- **内容获客资产**：把产品知识、客户问题、案例和业务经验，沉淀成可以持续被搜索、被理解、被信任的内容。
- **外贸实操 Agent Skills**：把信用证审核、客户开发等高频工作，做成可以安装、配置和重复使用的 Skill。
- **开源项目 [`hs-open-skills`](https://github.com/globalwinhs/hs-open-skills)**：目前已公开 [`lc-expert-o`](https://github.com/globalwinhs/hs-open-skills/tree/main/skills/lc-expert-o)，用于审核信用证草稿及信用证项下交单文件。

## 我相信的几件事

- 真正的复利获客，不是多找一次客户，而是每做一次获客，都留下一项能继续获客的资产。
- 长期信任和复利资产，比短期数据和捷径更重要。
- 工具负责放大和执行，人负责方向、判断与责任。
- 事实可核验、表达有边界，比数字漂亮和话说得满更重要。
- 真实行动和反馈，比完美准备和纸上理解更重要。
