# 何胜

> 让时间为你获客。

我正在把外贸获客中的经验、判断和流程，沉淀成可复用的行动指南与实操 Agent Skills。

面向外贸“时间穷人”：不要求你做更多，而是让每一次获客行动，都能留下一项继续为你工作的资产。

## 我在做的事

- **复利获客行动指南**：判断方向、建设入口、用内容建立信任，再把询盘反馈沉淀为下一轮增长的基础。
- **外贸实操 Agent Skills**：把信用证审核、客户开发等高频业务流程，做成可以安装、配置和重复使用的 Skill。
- **内容获客资产**：让文章、网站、案例和业务经验不再是一次性消耗，而是能够持续带来搜索、信任和询盘。

## 我相信

真正的复利获客，不是多找一次客户，而是每做一次获客，都留下一项能继续获客的资产。
